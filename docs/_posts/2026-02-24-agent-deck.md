Ever tried juggling Claude Code on 10 projects while OpenCode runs on 5 more? Your terminal becomes a graveyard of abandoned tabs where you've lost track of which agent is doing what. Agent Deck solves this by giving you a single TUI that manages all your AI coding sessions in one place.

Built in Go with the slick Bubble Tea framework, it supports Claude, Gemini, OpenCode, Codex and more through a unified interface. You get session forking, MCP pooling, and the ability to switch between agents without losing context. Think tmux but designed specifically for AI workflows - complete with a 'Conductor' mode that orchestrates multiple agents simultaneously.

With 1030+ stars and active Discord community, this is hitting a real pain point for developers already deep in AI-assisted coding. The project even includes Claude skills for self-documentation, showing the kind of meta-AI integration we're heading toward.
